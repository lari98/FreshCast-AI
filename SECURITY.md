# Security Policy

This is a portfolio project. Report vulnerabilities privately via GitHub
"Report a vulnerability" (Security tab) rather than a public issue.

- Never commit credentials, personal data or real store data; use synthetic data only.
- AWS access from CI uses GitHub OIDC (no long-lived keys).
