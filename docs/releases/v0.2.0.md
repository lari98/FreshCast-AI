# FreshCast AI v0.2.0 (2026-11-02)

## New
- **Retail chains and market map**: fictional chains (MarktHaus, PreisPunkt, AlpenFrisch) per DE/AT/CH market, chain filter, map tab, chain-aware policy replay and upload aliases.
- **Today tab**: prioritised tasks (approvals, expiry, stock-outs, demand spikes, closures).
- **Quick search** over tabs and items; **audit trail** with before/after values.
- **Live update**: the dashboard detects a new build and updates without closing tabs.
- **Security layers**: upload guard (magic bytes, control characters, payload patterns, optional ClamAV), API hardening (headers, size limit, rate limit), CSP, CSV formula neutralising, phased attack tests, security workflow.
- **New palette** "Aubergine & Teal" with computed contrast.

## Changed
- Production-mode run by default (`scripts/run-dashboard.ps1`, `-Dev` for hot reload); paged tables; faster upload analysis.
- Refactors: dashboard hooks and tab registry, `replay_report.py`, smaller `clean_sales` steps.

## Effect (measured)
- First load 11.4 s (dev) to 0.3 to 0.6 s; Verfall tab with 336 items 405 to 130 ms; Freigabe 342 to 144 ms.
- Core 169 tests / 96.36 %, API 48 tests / 96.35 %, dashboard 133 tests; linters, mypy, Bandit, pip-audit, npm audit clean.

## Limits
Synthetic data, assumed cost shares, no third-party penetration test, no deployed AWS run, frontend coverage not measured. See `docs/quality/test-report.md`.

## Upgrade
`git pull`, then `.\scripts\run-dashboard.ps1`. Settings in the browser are kept (`freshcast.settings.v2`).
