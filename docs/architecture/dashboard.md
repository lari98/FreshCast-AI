# Dashboard (phase 9)

Next.js (App Router, TypeScript) static export in `apps/dashboard`.

## Data source
- Default: `public/demo/data.json`, generated by `scripts/export_demo_data.py`
  (trained model, forecasts, synthetic stock lots, v1 replenishment proposal,
  DE/EN explanations). All data is synthetic and labelled as such in the UI.
- Optional: set `NEXT_PUBLIC_API_URL` to read `GET /v1/dashboard` from the API.
  **That endpoint does not exist yet** (planned); the payload is validated at runtime.

Regenerate demo data: `python scripts/export_demo_data.py`.

## Screens
Store/product filters, forecast chart with 80 % interval (SVG + data table
alternative), order proposal with explanation and a human approval button
(demo: orders nothing), stock lots sorted by use-by date.

## Accessibility (engineering goals, not a conformance claim)
Skip link, landmarks, unique region names, keyboard-focusable scroll regions,
visible focus, 44 px targets, light/dark themes, reduced motion, chart not
colour-only (dash style, risk text + symbol), `lang` on explanation text,
axe-core test in CI. Colour contrast is not covered by the jsdom test and
needs a manual/browser check; the `<html lang>` is fixed to `de` (the UI
language switch changes visible text only).

## Language and formats
DE/EN toggle; `Intl` number and date formatting. Currency formatting helper
exists (EUR/CHF) but prices are not yet shown.

## Known gaps
No auth in the dashboard; approve is local state only; no real API calls yet.
